## Installation

Download the desktop app for Windows, macOS, or Linux from the [official page](https://mrait.ca/go/freebrowser), install it like any normal application, and sign in. It's Chromium underneath — if you've used Chrome, the interface is immediately familiar.

## The dashboard

The dashboard is mission control: your profiles list, quick-launch buttons, profile groups, and account settings. Organize it from day one — group profiles by client, store, or project, because the grouping you choose at 5 profiles is the one you'll live with at 50.

## Profiles

Profiles are the core unit. Each one is a fully isolated browser environment with its own:

- **Cookies and sessions** — log in once, stay logged in
- **Fingerprint** — RoxyBrowser exposes 160+ parameters (user agent, screen, Canvas/WebGL, fonts, time zone, language, and more). The defaults are sensible; customize deliberately and keep profiles consistent.
- **Proxy binding** — one IP per profile is the clean setup

## Proxy setup

Inside a profile's settings, enter your proxy (host, port, username, password) and use the built-in check to confirm the IP and its location. Residential or mobile IPs are the practical choice for social and marketplace accounts. RoxyBrowser integrates the **RoxyIP** pool if you don't have a proxy provider yet.

## Extensions

Profiles support Chrome extensions — install them per profile or as part of a profile template. That's one more way each environment behaves like a real, individual person's browser.

## Synchronizer (Window Sync)

The synchronizer is the multi-account multiplier: open several profiles and perform the same action across all of them at once — same navigation, same clicks, same routine. For repetitive publishing and monitoring across many accounts, this is the feature that gives you your hours back.

## Team collaboration

With **Team Space**, you share specific profiles with teammates or VAs under role permissions — they work inside the profile without ever seeing the underlying logins. For agencies, this is the difference between secure delegation and password chaos.

## API and automation

Everything above is scriptable through the **API Flow** and the AI-agent layer: create and launch profiles, assign proxies, and drive workflows programmatically. If your operation is repetitive at volume, start here after you've outgrown manual work.
